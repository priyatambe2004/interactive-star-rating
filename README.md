# Interactive Star Rating Widget

An interactive and responsive star rating component that allows users to select a rating from 1 to 5 stars with instant visual feedback.

## Features

- **Interactive Rating:** Select a rating by clicking any star.
- **Hover Preview:** Preview ratings before making a selection.
- **Dynamic Updates:** Display the currently selected rating.
- **Visual Feedback:** Highlight stars based on hover and selection.
- **Responsive UI:** Simple and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
interactive-star-rating/
├── index.html

└── README.md
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in a web browser.
4. Hover over the stars to preview a rating.
5. Click a star to select a rating from 1 to 5.

- Managing hover and selected states separately.
